# Отчётник для другого отдела

Каждый отдел получает **свою копию** Отчётника: свои люди, проекты и отчёты. Отчёты разных отделов
друг другу не видны. Делается через шаблон — пустую Google Таблицу с кодом внутри.

## Для владельца шаблона (делается один раз)

1. Под рабочим аккаунтом откройте https://sheets.new и назовите таблицу «Отчётник — шаблон».
2. **Расширения → Apps Script** → вставьте `Code.gs` в файл «Код.gs» и создайте HTML-файл `Index`
   с содержимым `Index.html` — так же, как при первом запуске. Сохраните.
3. **Не разворачивайте шаблон и не открывайте его как приложение** — тогда в нём не будет ни данных, ни настроек.
4. **Настройки доступа** (кнопка справа вверху) → «Все в <компания>, у кого есть ссылка» → **Читатель** →
   скопируйте ссылку и отправьте коллегам вместе с инструкцией ниже.

Не делитесь своей рабочей таблицей: в ней все отчёты вашей команды. Шаблон — отдельная пустая таблица.

## Для отдела, который запускает свой Отчётник (~15 минут)

1. Откройте ссылку на шаблон → **Файл → Создать копию** → оставьте галочки как есть → **Создать копию**.
   Код скопируется вместе с таблицей. Дальше работайте только в своей копии.
2. В копии: **Расширения → Apps Script** → справа вверху **Начать развертывание → Новое развертывание** →
   шестерёнка → **Веб-приложение**:
   - Запуск от имени: **Я**;
   - У кого есть доступ: **Все в домене <компания>** (не «Все»!).
   **Развернуть → Предоставить доступ** → выберите рабочий аккаунт. Если появится «Приложение не проверено» —
   **Дополнительные настройки → Перейти на страницу… → Разрешить**: это ваш собственный скрипт.
3. Скопируйте **URL веб-приложения** (заканчивается на `/exec`) — это ссылка для вашей команды.
4. Откройте ссылку один раз — в таблице появятся листы. Заполните:
   - **Команда** — вы уже записаны тимлидом. Добавьте коллег: почта, имя, роль `участник` или `тимлид`;
   - **Настройки → Название команды** — будет в шапке приложения и в заголовке общего отчёта;
   - **Проекты** — ваш список проектов;
   - **Подсказка** — правила заполнения отчёта. Поменяйте текст под свою команду или удалите все строки
     под заголовком, чтобы подсказки не было.
5. Отправьте ссылку команде.

Напоминание в Slack по четвергам можно настроить в Slack: **Automations → New Workflow → On a schedule →
Send a message to a channel**, в сообщение вставьте ссылку на приложение. Для отбивок участникам в отчёте
каждого человека у тимлида есть кнопка «📋 Скопировать отбивку для Slack».

Если вместо приложения ошибка 413 или вечная загрузка — откройте ссылку в окне инкогнито и войдите только
рабочим аккаунтом: так бывает, когда в браузере открыто несколько Google-аккаунтов.
